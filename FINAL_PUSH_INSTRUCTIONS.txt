              TROUBLESHOOTING SI FALLA

Problema: "Build is still pending"
→ Espera 5 minutos más. Heroku tarda a veces.

→ git push origin main  (asegúrate de hacer push)
→ Heroku → Activity → Manual Deploy → Deploy Branch

Problema: "Application Error" después de deploy
→ Revisa: heroku logs --tail -a your-app-name
→ Busca líneas que empiezan con "Error"

Problema: No ves "deployed to Heroku" en logs
→ Está desplegando pero algo sigue fallando
→ Copia el error completo y analiza
