📌 ¿QUÉ NECESITAS HACER?

Solo 3 pasos para empezar a desarrollar:


PASO 1: CREAR LA ESTRUCTURA
═════════════════════════════════════════════════════════════════════════

Abre Command Prompt en esta carpeta y ejecuta:

    node setup-full.js

Esto tomará 2-3 segundos y creará:
  • 19 directorios (server + client con subdirectorios)
  • 13+ archivos de configuración
  • Estructura lista para desarrollar


PASO 2: INSTALAR DEPENDENCIAS
═════════════════════════════════════════════════════════════════════════

Luego ejecuta en orden:

    npm install
    cd server && npm install
    cd ../client && npm install
    cd ..

Esto tomará 10-15 minutos (depende de tu internet)


PASO 3: INICIAR DESARROLLO
═════════════════════════════════════════════════════════════════════════

Finalmente:

    npm run dev

Verás ambos servidores iniciando:
  • Frontend: http://localhost:3000  ← Tu app React
  • Backend:  http://localhost:3001  ← Tu API Node.js

¡Abre el navegador en localhost:3000!

⚙️ CONFIGURACIÓN NECESARIA

Después de setup, crea: server/.env

    NODE_ENV=development
    PORT=3001
    DATABASE_URL=postgresql://user:pass@localhost:5432/agora
    JWT_SECRET=cambia_por_algo_seguro_1234567890
    FRONTEND_URL=http://localhost:3000
    OPENAI_API_KEY=sk-...

(Copia desde server/.env.example)

🌍 DEPLOY EN HEROKU (DESPUÉS)

Está 100% configurado. Solo:

1. Push a GitHub
   git add .
   git commit -m "Initial commit"
   git push origin main

2. Heroku Dashboard → New app → Connect GitHub
3. Enable "Automatic deploys"
4. Configura variables en Heroku
5. ¡Listo! Auto-deploya en cada push

❓ PREGUNTAS FRECUENTES

P: ¿Port en uso?
R: Cambia PORT en server/.env

P: ¿npm install falla?
R: npm cache clean --force && npm install

P: ¿Database no conecta?
R: Verifica DATABASE_URL en .env y que PostgreSQL esté corriendo

P: ¿CORS error?
R: Verifica FRONTEND_URL en server/.env

P: ¿Necesito instalar PostgreSQL?
R: Para dev local sí. Para producción, Heroku Postgres está incluido.
