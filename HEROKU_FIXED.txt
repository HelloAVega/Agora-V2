PROBLEMA:
─────────────────────────────────────────────────────────────────────────
  ❌ sh: 1: vite: not found
  
Causa: Heroku no instalaba devDependencies necesarias para el build


SOLUCIÓN IMPLEMENTADA:
─────────────────────────────────────────────────────────────────────────

✅ 1. Actualizado: package.json
   • Versión Node específica: 18.x (en lugar de >=16.0.0)
   • Script nuevo: "heroku-postbuild"
   • npm versión: 9.x

✅ 2. Creado: .npmrc
   • Fuerza instalación de devDependencies
   • Solución: production=false

✅ 3. Actualizado: Procfile
   • De: web: npm run start
   • A:  web: node server/server.js
   • Más directo y eficiente

✅ 4. Actualizado: server/server.js
   • Sirve archivos estáticos del build
   • Maneja SPA routing
   • API en /api/**
   
✅ 5. Creado: heroku.yml
   • Configuración explícita de build
   • Variables de ambiente


FLOW DE BUILD EN HEROKU (AHORA CORRECTO):
─────────────────────────────────────────────────────────────────────────

1. Heroku detecta Node.js
2. Lee .npmrc → instala devDependencies
3. npm install (en root, server/, client/)
4. Ejecuta heroku-postbuild → cd client && npm run build
5. Genera /client/dist
6. Inicia: node server/server.js
7. Server sirve /client/dist como static files
8. SPA routing funciona con catch-all
