📋 REQUISITOS PREVIOS
─────────────────────────────────────────────────────────────────────
☐ Node.js 16+ instalado (https://nodejs.org)
☐ npm 8+ instalado (viene con Node.js)
☐ PostgreSQL instalado (para desarrollo local)
☐ Git instalado (para versionado)
☐ Un editor de código (VS Code recomendado)
☐ Command Prompt abierto en C:\Users\teamv\Downloads\Agora-V2


✅ CONFIGURACIÓN DEL PROYECTO
─────────────────────────────────────────────────────────────────────

PASO 1: Crear Estructura (1-2 minutos)
  ☐ Ejecutar: node setup-full.js
  ☐ Esperar a que termine (2-3 segundos)
  ☐ Ver mensaje: "✨ Project structure initialized!"
  ☐ Verificar que se crearon carpetas server/ y client/

PASO 2: Instalar Dependencias (10-15 minutos)
  ☐ Ejecutar: npm install
  ☐ Esperar a que termine
  ☐ Ejecutar: cd server && npm install
  ☐ Ejecutar: cd ../client && npm install
  ☐ Ejecutar: cd ..
  ☐ Verificar: No hay errores en la instalación

PASO 3: Configurar Variables de Ambiente (2 minutos)
  ☐ Copiar server/.env.example a server/.env
  ☐ Editar server/.env con tus valores:
    - NODE_ENV=development
    - PORT=3001
    - DATABASE_URL (tu postgres local)
    - JWT_SECRET (cambiar a algo seguro)
    - FRONTEND_URL=http://localhost:3000
    - OPENAI_API_KEY (opcional por ahora)
  ☐ Guardar .env


🚀 DESARROLLO
─────────────────────────────────────────────────────────────────────

  ☐ Ejecutar: npm run dev
  ☐ Ver output: "Frontend running on http://localhost:3000"

  ☐ Esperar a que ambos estén listos

Paso 2: Abrir la Aplicación
  ☐ Abrir navegador: http://localhost:3000
  ☐ Ver página de inicio de Ágora
  ☐ Verificar que carga sin errores

Paso 3: Verificar Backend
  ☐ Abrir: http://localhost:3001/api/health
  ☐ Ver respuesta: { "status": "ok", "timestamp": "..." }

⚠️ ERRORES COMUNES Y SOLUCIONES
─────────────────────────────────────────────────────────────────────

Port en uso:
  ☐ Problema: "Port 3000 already in use"
  ☐ Solución: Cambia PORT en server/.env o cierra app anterior

Módulo no encontrado:
  ☐ Problema: "Cannot find module 'X'"
  ☐ Solución: npm install en la carpeta correspondiente

BD no conecta:
  ☐ Problema: "Connection refused"
  ☐ Solución: DATABASE_URL incorrecto o PostgreSQL no corriendo

CORS error:
  ☐ Problema: "CORS policy blocked"
  ☐ Solución: Verifica FRONTEND_URL en server/.env

Vite error:
  ☐ Problema: "Cannot find module '@vitejs/plugin-react'"
  ☐ Solución: cd client && npm install @vitejs/plugin-react
