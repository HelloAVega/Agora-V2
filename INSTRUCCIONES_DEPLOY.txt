📞 TROUBLESHOOTING RÁPIDO
═════════════════════════

Problema: "git push" dice "permission denied"
Solución: 
  - Verifica que tengas SSH configurado: ssh -T git@github.com
  - O usa HTTPS en lugar de SSH: git remote -v

Problema: Heroku build aún falla con "vite: not found"
Solución:
  - Verifica que hiciste git push (cambios deben estar en GitHub)
  - Ejecuta: heroku logs --tail -a tu-app-name
  - Busca si se ejecutó "npm run install:all"

Problema: No ves el build nuevo en Heroku
Solución:
  - Verifica en GitHub que el push llegó
  - En Heroku Dashboard, en "Deployment", asegúrate que está conectado a GitHub
  - Verifica que "automatic deploys" está habilitado
  - Prueba un "Manual Deploy" desde el dashboard
